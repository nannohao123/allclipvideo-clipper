AllClipVideo Clipper

Alat pribadi milik satu pengguna untuk mengunggah klip video pendek ke akun miliknya sendiri.

AllClipVideo Clipper adalah alat personal (single-user) yang digunakan pemiliknya untuk mengunggah klip video pendek ke channel YouTube miliknya, AllClipVideo (youtube.com/@AllClipVideo35), melalui YouTube Data API v3, dan ke akun TikTok miliknya, @clippaddicted, melalui TikTok Content Posting API (mode draf). Alat ini bukan layanan publik dan tidak ditawarkan kepada pengguna lain.

Kebijakan Privasi

Berlaku sejak 11 Oktober 2026.

1. Data yang diakses

Dengan persetujuan pemilik akun (OAuth 2.0), aplikasi mengakses:

  • YouTube API: scope youtube.upload dan youtube.readonly — untuk mengunggah video dan membaca informasi dasar channel/video milik pemilik sendiri.
  • TikTok API: scope user.info.basic dan video.upload — untuk memastikan akun yang terhubung adalah akun pemilik sendiri dan mengunggah video sebagai draf.
  • Berkas video dan metadata unggahan (judul, deskripsi, hashtag) yang disiapkan pemilik.

2. Penggunaan data

Data hanya digunakan untuk autentikasi dan pengunggahan konten ke akun pemilik sendiri. Data tidak dijual, disewakan, dibagikan kepada pihak ketiga, atau digunakan untuk periklanan. Penggunaan data dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

3. Penyimpanan

Token OAuth dan kredensial disimpan hanya di server pribadi pemilik dengan izin berkas terbatas (mode 600) dan tidak pernah dipublikasikan.

4. Pencabutan akses

Pemilik dapat mencabut akses aplikasi kapan saja melalui Google Permissions dan pengaturan aplikasi di TikTok; pencabutan membuat token yang tersimpan tidak berlaku lagi.

5. Layanan pihak ketiga

Aplikasi hanya berinteraksi dengan API Google/YouTube dan TikTok, dan tunduk pada Ketentuan Layanan YouTube, Ketentuan Pengembang TikTok, serta kebijakan privasi masing-masing platform.

6. Perubahan & kontak

Perubahan kebijakan akan diterbitkan di halaman ini. Pertanyaan dapat disampaikan melalui channel publik pemilik di YouTube @AllClipVideo35 atau TikTok @clippaddicted.
